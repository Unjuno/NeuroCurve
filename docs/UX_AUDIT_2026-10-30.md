## H / T / D / C / U acceptance record

**H — falsifiable hypothesis:** At viewport widths 390 and 1440 CSS pixels, ordinary pen x-reversals must yield a valid differentiable function; after changing suite selection or drawing, the old aggregate cannot be presented as current; six-task CPU smoke must finish without JS errors.

**T — minimal validation:** Five normalizer unit cases, four DOM/contract cases, one mocked six-task UI scenario, and one real six-task CPU browser run; run with Node 22.16.0 / Chromium 144.0.7559.96. Stop at the first reproducible unexpected failure.

**D — decision:** PASS only if the source checks, complete unit suite, browser state checks and one real CPU smoke all pass; otherwise FAIL. GPU and production sharing are UNCERTAIN by design.

**C — counter-hypotheses:** Strongly looping or nearly vertical sketches cannot represent a single-valued function and must be rejected; long strokes are downsampled and can lose fine oscillations; CPU and GPU numerical precision are different; timing is hardware-dependent; a client-asserted score is not a certified competitive ranking.

**U — uncertainty:** Finite sampled PCHIP error, dataset/model sampling variability, floating-point precision and browser scheduling are dominant sources. Combined standard uncertainty `u_c` and coverage factor `k` are not estimated from the single-seed smoke; a separate multi-seed, device-controlled experiment is required. Do not interpret score differences as statistical significance.
